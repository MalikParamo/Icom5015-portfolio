## Overview

This is a curated portfolio of five AI projects built during **ICOM5015 (Artificial Intelligence)** at UPR Mayagüez in Spring 2026. Each project applies a distinct family of algorithms and techniques to solve real computational problems.

## Projects

### **PA1**: Pure Python vs. NumPy — Performance Benchmarking
- **Date**: Feb 25, 2026
- **Topic**: Numerical Computing
- **Key Result**: 7,288× speedup at scale (500×500 matrix)
- **Techniques**: Vectorization, benchmarking, O(n³) analysis
- **Folder**: [PA1/](PA1/)

### **PA2**: Rational Agent Design — PEAS Framework
- **Date**: Mar 6, 2026
- **Topic**: Intelligent Agents
- **Key Result**: Model-based agent outperformed in constrained spaces
- **Techniques**: PEAS framework, agent design, simulation
- **Folder**: [PA2/](PA2/)

### **PA3**: Solving Problems by Search — Visibility Graph Navigation
- **Date**: Apr 22, 2026
- **Topic**: Search Algorithms
- **Key Result**: A* expanded only 14 nodes to find optimal path
- **Techniques**: A*, UCS, Greedy BFS, visibility graphs, heuristic design
- **Folder**: [PA3/](PA3/)

### **PA4**: Beyond Classical Search — Local Search Algorithms
- **Date**: Apr 28, 2026
- **Topic**: Local Search & Optimization
- **Key Result**: 400 experiments comparing HC, SA, and random-restart
- **Techniques**: Hill climbing, simulated annealing, 8-queens, 8-puzzle
- **Folder**: [PA4/](PA4/)

### **PA5**: Briscas AI — Adversarial Card Game Agent
- **Date**: May 18, 2026
- **Topic**: Adversarial Search
- **Key Result**: 92% win rate vs. random, 58% vs. heuristic agent
- **Techniques**: Minimax, alpha-beta pruning, Monte Carlo sampling
- **Folder**: [PA5/](PA5/)

### **CSP**: CSP Simplified — Modeling Einstein's Riddle
- **Date**: May 8, 2026
- **Topic**: Constraint Satisfaction
- **Key Result**: 3 representations analyzed for efficiency and readability
- **Techniques**: CSP, constraint propagation, backtracking, SAT/ILP
- **Folder**: [Simplified/](Simplified/)

Feb 25 2026  ·  Numerical Computing
Pure Python vs. NumPy — Performance Benchmarking
Implemented element-wise 1-D vector multiplication and true 2-D matrix multiplication in both pure Python and NumPy, then measured median runtime across 15 trials at five input sizes to quantify the performance gap and explain the architectural reasons behind it.
NumPy Vectorization Benchmarking Python O(n³) Analysis
7,288×Peak speedup at 500×500 matrix
33×Speedup at 500-element vector
15Timed trials per data point
What I Did
Built py_elementwise and np_elementwise — the 1-D vector multiplication functions for both implementations. The Python version uses an explicit loop over paired elements O(n); the NumPy version uses the native a*b vectorized operator. Both functions fed into a shared median_time benchmarking harness with warm-up runs and a fixed random seed.
Key Finding
The speedup for 1-D operations grew from 1.1× at n=10 to 33× at n=500, while matrix multiplication hit 7,288× at 500×500 — consistent with the O(n³) interpreter overhead of nested Python loops vs. BLAS-backed NumPy and its contiguous memory layout. Big-O alone doesn't capture the constant factor difference.

Designed and compared three agent architectures — Simple Reflex, Random, and Model-Based with DFS exploration — across a two-location vacuum world and a 2D grid environment with obstacles. Ran 50 randomized trials and a constrained corridor experiment to isolate policy differences.

Solving Problems by Search — Visibility Graph Navigation
Reduced a continuous obstacle-filled plane to a 35-node visibility graph and compared A*, Greedy BFS, and UCS on finding the shortest path. Separately modeled the missionaries and cannibals problem as a finite 20-state graph and solved it optimally with BFS.
A* Search Visibility Graph UCS · Greedy BFS BFS Heuristics
13.342Optimal path cost (A* and UCS)
14Nodes expanded by A*
11Optimal river crossings (BFS)
What I Did
Wrote the full methodology and led the analysis for Problem 3.7 — the visibility graph experiment. This included explaining the reduction from infinite continuous space to 35 nodes, documenting the 111-edge graph construction (obstacle penetration tested via 3 interior sample points), and interpreting the node-expansion comparison between all three algorithms.
Key Finding
A* expanded 14 nodes; UCS needed 31 to confirm the same optimal path; Greedy found a slightly worse path in only 3 expansions. UCS matching A*'s path cost confirmed the heuristic is admissible. The key insight: reducing an intractable continuous problem to a finite graph before searching is often more impactful than algorithm choice.

Apr 28 2026  ·  Local Search
Beyond Classical Search — Local Search Algorithms
Ran 400 experiments comparing steepest-ascent hill climbing, first-choice HC, random-restart HC, and simulated annealing on the 8-queens and 8-puzzle problems. Measured success rate and average search cost to understand how algorithm choice interacts with problem structure.
Hill Climbing Simulated Annealing 8-Queens 8-Puzzle AIMA Repository
100%Random-restart success (both)
86%Simulated annealing on 8-queens
400Total experimental runs
What I Did
Designed the experimental protocol — 50 independent trials per algorithm per problem, recording both whether the goal was reached and total candidate states evaluated — and wrote the Methodology and Results sections. Generated the master comparison table covering all eight algorithm-problem combinations and co-authored the interpretation of why SA succeeds on 8-queens but fails on 8-puzzle.
Key Finding
SA solved 86% of 8-queens instances but only 16% of 8-puzzle. SA's willingness to accept worse moves is an advantage in high-optima, many-local-minima spaces but costly overhead on the more directed 8-puzzle. Random-restart HC was the only algorithm to hit 100% on both, proving that diversification reliably beats clever local moves when the landscape is unknown.

May 8 2026  ·  Constraint Satisfaction
CSP Simplified — Modeling Einstein's Riddle
Modeled the Zebra Puzzle as a Constraint Satisfaction Problem using three distinct representations — Position-Based, House-Based, and Permutation/Boolean — and analyzed each for solver efficiency, human readability, and compatibility with SAT/ILP systems.
CSP Constraint Propagation MRV · LCV SAT / ILP Backtracking
3Representations analyzed
125Binary vars (permutation model)
5×5Constraint matrix structure
What I Did
Participated in the comparative analysis of all three encodings. The position-based model (variables = house positions 1–5, adjacency as arithmetic) was identified as most balanced — compact, compatible with MRV/LCV heuristics, and readable. The boolean model (125 binary variables, SAT-compatible) offered raw computational power at the cost of total opacity.
Key Finding
Each representation captures the same problem through a different lens: the house model mirrors human reasoning; the position model is the most balanced for algorithmic implementation; the boolean model scales to industrial CSP solvers. The choice isn't about which is correct — it's about which fits the goal, whether that's explainability, efficiency, or scalability.

May 18 2026  ·  Adversarial Search
Briscas AI — Adversarial Card Game Agent
Built an AI agent for the two-player Spanish card game Briscas using Averaging over Clairvoyance: sampling 15 possible opponent hands and evaluating each via depth-4 minimax with alpha-beta pruning. Evaluated against a random and a rule-based heuristic agent across 150 total games.
Minimax · Alpha-Beta Monte Carlo Sampling Partial Observability PettingZoo Game AI
92%Win rate vs. random agent
58%Win rate vs. heuristic agent
+31.2Avg. score margin vs. random
What I Did
Designed the evaluation protocol — 50 games per matchup with player positions swapped at game 25 to control for first-move advantage — and wrote the Methodology and Results sections. Produced the performance summary table with 95% confidence intervals, and wrote the statistical analysis explaining what the win-rate CIs do and don't prove with a 50-game sample.
Key Finding
The AoC agent achieved a 92% win rate vs. random (CI [80.7%, 97.3%]) and 58% vs. the heuristic (CI [44.4%, 70.6%]). The 58% result is the meaningful one — it shows the agent is doing genuine strategic reasoning against a structured opponent, not just exploiting weak play. Performance stabilized at 10–15 opponent hand samples, balancing accuracy and runtime.
